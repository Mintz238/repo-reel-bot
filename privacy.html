Privacy Policy — Repo Reel bot

Last updated: 30 October 2026

Repo Reel bot ("the App") is a personal automation tool used only by its owner to upload self-made videos to their own TikTok account. This policy explains what data the App handles.

1. Data we receive from TikTok

  • Basic profile (scope user.info.basic): open ID, display name and avatar of the connected account, used only to confirm which account is connected.
  • Access and refresh tokens: used only to upload videos to the connected account's drafts (scope video.upload).

The App does not access followers, messages, comments, analytics, contacts or any other user's data.

2. How data is stored

Tokens are stored encrypted-at-rest on the owner's private home server in a file readable only by the App's service account. Data is never sold, shared with third parties, or used for advertising.

3. Data from other sources

Video content is generated from public GitHub repository information (names, descriptions, star counts, README text and images published by the repository authors).

4. Retention and deletion

Tokens are kept only while the App is connected. To delete them, disconnect the App in TikTok (Settings and privacy → Security → Apps and services permissions); the owner then deletes the stored tokens. Generated videos are kept on the server for at most 20 runs and then deleted automatically.

5. Children

The App is not directed to children and is used only by its adult owner.

6. Contact

Questions or deletion requests: contact the owner via the Facebook Page "Cái này để đi cmt dạo".
